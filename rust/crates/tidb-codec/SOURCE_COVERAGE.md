# Codec source coverage

This inventory bounds dependency-closed production codec leaves, including the
scalar formats used by `tidb-txnkv::CommonHandle` and the minimal table-key
row/index classifier. It does not treat a fixture as an implementation and does
not claim temporal, JSON, vector, or general collation behavior before those
owning Rust types exist. Go runtime layout and unsafe word-at-a-time operations
are not compatibility contracts; their observable encoded bytes remain exact.

The public `encode_key` domain exactly matches `tidb-datatype::Datum`: NULL,
Int, UInt, Decimal, Real, String, and Bytes. Decimal encoding consumes the
lossless coefficient and storage scale, not `Display`, so hidden arithmetic
precision is not rounded away at the codec boundary. BinaryLiteral is not
silently accepted through a codec-only helper: Go's production path is a
distinct Datum kind normalized through typed `ToInt` conversion, so that kind
must land as one exhaustive workspace migration before this domain expands.
