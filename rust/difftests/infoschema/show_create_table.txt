# CAPTURED from a running TiDB (`gorun`): SHOW CREATE TABLE
# information_schema.<t> for every table `tidb-session`'s infoschema serves,
# in the order the served-table registry lists them.
#
# ONE CORRECTION applied to the raw capture: `gorun` never applies
# `deprecate-integer-display-length`, so it prints `bigint(21)` where a real
# tidb-server prints `bigint` (Go `CompactStr` hides the width whenever
# `TiDBStrictIntegerDisplayWidth` is set, which it is on a server). The
# integer display widths below were therefore stripped; every other byte is
# the capture verbatim.
#
# TWO BLOCKS ARE DERIVED, NOT CAPTURED: `TIDB_SERVERS_INFO` and
# `CLUSTER_INFO` were added after this capture was taken, so their blocks are
# written from Go's own column declarations (`pkg/infoschema/tables.go`'s
# `tableTiDBServersInfoCols` and `tableClusterInfoCols`: name, type and size,
# with no flags and no defaults) rendered under the conventions every
# captured block above establishes. Re-capture them the next time `gorun` is
# available.
#
# Go declares a `comment` on `CLUSTER_INFO`'s `SERVER_ID`, which renders as a
# trailing `COMMENT '...'`; among the served tables it is the only one that
# declares any. It is the sole column comment below.
