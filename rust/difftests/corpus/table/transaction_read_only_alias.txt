## varsutil.go:checkReadOnly, exercised end-to-end by
## pkg/executor/set_test.go:TestSetVar. `tx_read_only` and
## `transaction_read_only` are one compatibility-only value: OFF accepts
## false but rejects true, while ON/WARN permit true without making DML
## read-only. The seed intentionally has no global-variable store, so this
## table corpus stays on its fully modeled session path.

set tidb_enable_noop_functions = on

set transaction read only
