## FIND_IN_SET(str, strlist) is a comma-separated list lookup, 1-based, 0 when
## absent. It does NOT trim: ' foo ' is a distinct element from 'foo', and a
## trailing comma creates a real empty element, so FIND_IN_SET('', 'foo,bar,')
## is 3 while FIND_IN_SET('', '') is 0. A needle that itself contains a comma
## can never match. Either argument NULL yields NULL.
##
## INSERT(str, pos, len, newstr) replaces `len` characters starting at the
## 1-based `pos`. An out-of-range pos returns `str` UNCHANGED rather than NULL
## or an error -- but only when no other argument is NULL, since NULL still
## wins over the out-of-range pos (the `-1, nil` rows). A negative or
## overlong len truncates the tail. Positions and lengths are character counts,
## which the CJK half of the table is there to prove.
