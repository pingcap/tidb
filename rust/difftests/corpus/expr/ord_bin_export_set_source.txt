## ORD returns the FIRST character's multi-byte code read as a big-endian
## integer over its encoded bytes -- not a Unicode code point. Under utf8mb4
## '你' is 0xE4BDA0 = 14990752 and the 4-byte emoji is 4036989325, which is
## past 2^31 and so pins that the accumulator is 64-bit. Only the first
## character matters ('23' and 23 both give 50), and an empty string is 0.
##
## BIN is CONV(n, 10, 2) over an ETInt-coerced argument, so a numeric-prefix
## string parses its prefix ('10.2aa' -> 10) and a wholly non-numeric string is
## 0. A negative value prints the 64-bit two's-complement pattern.
##
