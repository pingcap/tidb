## Structural audit 2026-11-25: call-site and message parity

Tools: `tidb-wt/tools/drift/callsite_parity.py` (a ported Go function called from far fewer Rust fns than Go functions: 861 raw, 354 after dropping accessors) and `message_parity.py` (user-facing Go warning/error texts absent from rust/: 101). Leads verified against gomaster (testkit probe) and a live Rust unistore server. All seven below were fixed on 2026-11-25 with Go-pinned tests (the date-warning fix also unified three hand-written copies of Go `checkMonthDay`'s text -- cast, DATE_ADD family, CONVERT_TZ -- into `time_fn::calendar::go_parse_time_error_value`); kept here as the record of what the audit tools find:

- JOIN ... ON with a subquery fails in Rust with `planCtx is required when rewriting node: '*ast.SubqueryExpr'` (also `ExistsSubqueryExpr`, `PatternInExpr`), for SELECT, multi-table UPDATE and DELETE. Go supports scalar and EXISTS subqueries in ON and answers `ON condition doesn't support subqueries yet` for IN.
- Row operands (`CheckArgsNotMultiColumnRow`, Go 8 rewriter call sites, Rust 1): `CASE WHEN (1,2)`, `(1,2) BETWEEN ..`, `1 BETWEEN (1,2) AND ..`, `ABS((1,2))`, `CONCAT((1,2),..)` answer an internal `builtinRowSig.vecEvalString() should never be called` and `(1,2) REGEXP` answers `this scalar function is not yet ported`; Go answers 1241 `Operand should contain 1 column(s)`.
- MPP-enforced warnings (`RaiseWarningWhenMPPEnforced`, Go 15 sites, Rust 1): the `full outer join` and left/right-conditions join warnings are missing.
- 1659 `Field '%s' is of a not allowed type for this type of partitioning`: Go names the column `db.table.col`, Rust the bare column.
- `handleInvalidTimeError` (Go 23 call sites, Rust 4): ADDDATE / DATE_ADD / CONVERT_TZ warn with the raw input (`'2020-02-30'`) where Go warns with the parsed time (`'2020-2-30'`).
- ROUND(int, negative frac) rounds through float half-to-even (Go 06441e2a681: exact integer, half away from zero).
- EXCHANGE PARTITION's row check runs before generated columns / auto-increment ids are filled (Go d3a10d865e6).
