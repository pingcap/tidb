## Implementation and removals


The shared native owner constructs unregistered collectors and binds all source
observers. First PD initialization selects constant labels with one SeqCst CAS,
publishes the labeled collectors, rebinds consumers, registers the exact source
list and initializes resource-group metrics. A consumer runs immediately when
registered and again during first initialization. Arc snapshots, short locks and
serialized callbacks make publication safe in Rust; no lock spans an RPC.
Resource-group initialization intentionally has no once guard. Duplicate registry
errors panic, and a failed first PD initialization still consumes the once guard.

The generator checks both complete file inventories and production SHA-256 pins.
It emits typed Rust collectors and all prebound observer aliases. Names, help,
label order, buckets and source registration omissions come from Go. In particular,
Go constructs but does not register OngoingRequestCountGauge, and its
CmdFailedDurationGetAllKeyspacesGCStates aliases the success vector. Both are
preserved and tested, not silently corrected.

Native stats.rs's six PD collector definitions are removed. RetryClient initializes
the owner before connecting. Existing PD timing and TSO batch adapters use shared
collectors; bucketed/non-bucketed region calls share Go's label. Metadata total
duration is observed once per logical command, including failures; recovered
attempts do not emit failed-command duration. Go TSO completion retains separate
success/failure timing. No metadata counters or external-timestamp command labels
are invented. Broader root/TSO request/wait/stream instrumentation remains open.

TiDB's separate six-collector PD dashboard implementation and handwritten label
initialization list are removed. Its metrics.rs is now a thin observation adapter
using the same native owner. Failed metadata observations increment both total
and failed duration and no longer create metadata labels in the TSO stream
histogram. Delivered TSO errors use the failed wait observer; timeout/disconnection
outside the delivered-result branch does not fabricate a successful wait sample.

Native changes are src/pd/metrics.rs, generated src/pd/metrics/* definitions,
metrics tests, src/{lib,stats}.rs, src/pd/{mod,retry}.rs, the pinned generator,
Go oracle inputs/results and package receipts. TiDB changes are the maintained
vendor sync, src/metrics.rs and src/client/mod.rs in tidb-pd-client, its sync log,
this receipt and the full-picture plan/audit links. No dependency version,
Cargo lockfile or protocol schema changed. Protocol outputs were regenerated by
the sync script and remained unchanged.
