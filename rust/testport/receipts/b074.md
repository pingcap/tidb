## Gaps

- go-parity-gap: `expr_to_pb.go`'s conversion pipeline (`ExpressionsToPBList`,
  `ProjectionExpressionsToPBList`, float-constant lowering incl. the -0.0
  ATAN2 guard at expr_to_pb.go ~line 142, the `PushDownTestSwitcher`/
  `PanicIfPbCodeUnspecified` failpoints) is deliberately unported;
  `pb_predicate.rs` lowers only the integer/string predicate subset and
  `infer_pushdown.rs` carries Flash/TiKV admission as policy functions without
  a failpoint channel (rows 481–483).
- go-parity-gap: `exprctx.CtxWithHandleTruncateErrLevel`
  (`pkg/expression/exprctx/context.go:203`) is on exprctx.rs's deferred-list of
  umbrella pieces; simple_expr.rs documents the boundary for its only call site
  (generated-column truncate-warning suppression). Row 484.
- go-parity-gap: `NewValuesFunc` (`expression.go:1168`) is not transcreated.
  Row 488.
- go-parity-gap: `Expression.MemoryUsage()` / struct-size accounting is a
  documented DEFERRED unit (column.rs module header). Row 498.
- go-parity-gap: `IllegalFunctions4GeneratedColumns` was transcreated outside
  this crate as `DISALLOWED_FUNCTIONS` in `tidb-executor/src/generated_column.rs`;
  comparing it against `GetBuiltinList()` from tidb-expr would invert layering.
  Row 520.
- go-parity-gap: parameter-marker constants refuse evaluation in the fold path
  (`Constant::eval` reports deferred/parameter constants unsupported), so Go's
  plan-cache halves of TestEvaluateExprWithNullAndParameters (deferred
  `Constant(lt(NULL, ?))`, `SetSkipPlanCache`→`UseCache` flip) cannot run; and
  this workspace's `new_function("cast")` refuses cast nodes where master's
  `newFunctionImpl` routes them to BuildCastFunction, so the
  ParseToJSONFlag strip-and-persist walk of TestEvaluateExprWithNullNoChangeRetType
  also cannot run. Rows 491(stub)/492.
- go-parity-gap: `Expression.Decorrelate` and `PropagateType` are deferred
  units, leaving TestConstant's Decorrelate-identity and ETReal-retyping
  assertions unsupported. Row 493 stub.
- DIVERGENCE (not blocking these rows' mechanics): master added a tenth optional
  property `OptPropSessionContext` (`exprctx/optional.go:79`,
  `expropt/sessioncontext.go`) and a tenth ExprContext field
  `WithNewCollationEnabled`/`NewCollationEnabled` (`exprstatic/exprctx.go`,
  `exprctx.BuildContext`). This worktree's Go snapshot and its transcreation
  predate both (crate models `OPT_PROPS_CNT = 9` and no per-context collation
  mode). The carriers therefore pin identical mechanics over nine keys;
  landing the master delta will require production symbols first, not test
  edits.
- PORT SEAM: production `new_function_impl` folds rebuilt nodes with the
  rewriter-tier fold, which does not carry Go's `specialFoldHandler`
  (`Ifnull`/`If`/`Case`/`IsNull`) set that master applies inside every
  `NewFunction`. The test-local `MasterFunctionBuilder` composes the two
  ported halves (`new_function` typing + public `fold_constant_with`)
  to reproduce master behavior; wiring them inside `new_function_impl` itself
  would close the seam with no test change needed.
