# testport batch b063 — `pkg/util/rowcodec`

Gate command (as assigned):
`cargo nextest run --locked -p tidb-protocol -E 'not test(/bench/)' --no-fail-fast`

## Crate-mapping note

The manifest maps base package `pkg/util/rowcodec` to crate `tidb-protocol`,
but `tidb-protocol` contains only MySQL packet framing and has zero rowcodec
symbols; the complete typed transcreation lives in `rust/crates/tidb-codec`
(`src/rowcodec.rs`, documented as "Complete typed package boundary for
`pkg/util/rowcodec`"). As in batches b050 and b062, the mandated gate was run
verbatim AND the owning-crate gate was run alongside it; both are reported.
All code edits this batch are confined to
`rust/crates/tidb-codec/tests/rowcodec_package_source.rs` plus this receipt;
no production code changed.

## Method note

Every pre-existing Rust counterpart listed below was re-derived line-by-line
against `git show origin/master:<file>` sources (tests + the exercised
functions in `common.go`, `decoder.go`, `encoder.go`, `row.go`), not trusted
from comments. Where the existing ports pinned less than the Go test does,
this batch added complementary `#[test]` functions in the same file (same
helpers: `field()`, `column()`, local import set), so one file keeps the whole
package-level obligation.
