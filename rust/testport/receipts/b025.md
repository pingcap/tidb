# b025 — port `pkg/util/memory` unit tests to `tidb-util`

## Coverage note

The `tidb-util` crate already carries extensive ports of the Go memory tests
(inline `#[cfg(test)] mod tests` in
`crates/tidb-util/src/memory/{tracker,pool,action,arbitrator_utils,mem_state_recorder,process}.rs`
plus `memory/arbitrator/tests/{mod,full_flow,bench}.rs`). This batch audited
every Go test function on `origin/master` against those existing Rust tests,
re-deriving intent from the Go sources, and added the missing gap markers.

Go test files read from `origin/master`: `tracker_test.go`, `pool_test.go`,
`arbitrator_test.go`, `bench_test.go`, `main_test.go`.
