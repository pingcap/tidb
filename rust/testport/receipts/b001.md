## go-parity-gap list

- HostedEmbedding config section and its "can only be configured for
  starter deploy mode" gate are not transcreated.
- `Security.ClusterSecurity()` / `ToTLSConfig()` are not transcreated.
- `Log.ToLogConfig()` is not transcreated (log-config derivation pinned via
  `get_disable_timestamp` instead).
- `AdjustStarterConfig` and its TLS-env handling are not transcreated.
- `GetMaxAllowedPacket` is not transcreated.
- Starter default `StarterParams.MaxImportDataSize = 25 GiB` on Load is not
  applied by Rust `load_str`.
- `Experimental.AllowEnableForeignKeyCheckInSharedLock` field is absent, so
  that line of the Go bulk-override fixture is omitted.
- `TokenLimit` is u32 in Rust vs uint64 in Go: a 99999999999 literal errors
  at parse time instead of decoding then clamping to MaxTokenLimit.
