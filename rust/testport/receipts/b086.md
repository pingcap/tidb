## The one real functional port

`TestWrapCastForAggFuncs`
(`pkg/planner/core/casetest/rule/rule_inject_extra_projection_test.go:31`) is
the only unit-shaped test in the slice: it builds SUM descriptors directly via
`aggregation.NewAggFuncDesc` and drives the mode-gated
`coreusage.WrapCastForAggFuncs` (`cast_misc.go:25`) — no session or SQL. The
Rust port reuses `tidb_expr::aggregation::{AggFuncDesc::new,
BaseFuncDesc::wrap_cast_for_agg_args}` (already transcreated: descriptor.rs:86
mirrors descriptor.go:47; base_func.rs mirrors base_func.go:478 with
typeInfer4Sum at :215-237) and reproduces the 5-line planner gate verbatim as
a local helper in
`rust/crates/tidb-planner/tests/rule_inject_extra_projection_wrap_cast_source.rs`.
All
three behavior classes are asserted: every non-Final/Partial2 mode's wrapped
argument byte equals RetTp byte after wrapping; Final/Partial2 arguments stay
byte-identical to the pre-call clone; RetTp itself never changes post-build.
Int-family args (TypeLong/TypeLonglong/TypeInt24 → NewDecimal retTp) provide
the discriminating cases exactly as they do in Go. Port name:
`wrap_cast_for_agg_funcs_gates_final_and_partial2_modes`.
