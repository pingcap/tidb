## Source and implementation findings

The current Rust DDL tier applies metadata changes synchronously and does not
model the Go DDL job queue or intermediate `StateDeleteOnly`, `StateWriteOnly`,
`StateWriteReorganization`, rollback, and reorg-worker boundaries. The ignored
gaps cite the relevant Go test and production source locations, including:

- `pkg/ddl/index.go` for exact-name index visibility.
- `pkg/executor/infoschema_reader.go` for SHOW INDEX primary-row synthesis.
- `pkg/ddl/table_cache.go` and `pkg/ddl/db_cache_test.go` for cache state and
  lease behavior.
- `pkg/ddl/copr/copr_ctx.go` for the removed coprocessor context helpers.
- `pkg/ddl/column_type_change_test.go` and the DDL worker failpoints for
  changing-column/backfill behavior.

The branch no longer contains the former Rust `ddl_copr` facade. Therefore all
four Go copr tests are explicit ignored gaps; no removed or disconnected API is
claimed as an existing port.
