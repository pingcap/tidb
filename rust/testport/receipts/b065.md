# b065 — port `pkg/kv` Go unit tests to `tidb-txnkv`

Go code: pkg/kv

## Scope note

The owning crate already carried a near-complete translation of every
business-semantic non-benchmark test in `pkg/kv` in
`crates/tidb-txnkv/tests/kv_package_source.rs` and
`crates/tidb-txnkv/tests/interface_source.rs` (TestInterface lives there).
This batch re-derived each Go test's intent from `origin/master:pkg/kv/*`
and verified every existing Rust assertion against master's source. The full
Go package inventory is 30 tracked artifacts (5,145 Go/Bazel lines):
production, tests, mocks, fault-injection support, benchmarks, and the build
target; it has no generated or platform-specific variants. The rolling master
delta in `checker.go`/`checker_test.go` adds `tipb.ExprType_MaxCount` and
`ExprType_MinCount` support; Rust now carries those identities in the native
checker and executable source-derived regression.
