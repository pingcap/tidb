# b065 — port `pkg/kv` Go unit tests to `tidb-txnkv`

Go code: pkg/kv

## Scope note

The owning crate already carried a near-complete translation of every
business-semantic non-benchmark test in `pkg/kv` in
`crates/tidb-txnkv/tests/kv_package_source.rs` and
`crates/tidb-txnkv/tests/interface_source.rs` (TestInterface lives there).
This batch re-derived each Go test's intent from `origin/master:pkg/kv/*`
(the branch snapshot differs from master only in `checker.go` /
`checker_test.go`: master added `tipb.ExprType_MaxCount`/`MinCount` support),
verified every existing Rust assertion against master's source, and added the
one missing master behavior as an explicit parity-gap test.

## Gaps

- go-parity-gap: master's `pkg/kv/checker.go::supportExpr` accepts
  `tipb.ExprType_MaxCount` (3023) and `tipb.ExprType_MinCount` (3022); the
  Rust `src/checker.rs` was transcreated from a pre-MaxCount tipb snapshot
  and rejects them. Master's two extra assertions are pinned as
  `#[ignore = "go-parity-gap: ..."]` in
  `master_max_count_and_min_count_expr_types_are_pushed_down`.
- Go benchmarks (`BenchmarkIsPoint`, `BenchmarkMemAwareHandleMap`,
  `BenchmarkNativeHandleMap`) are excluded by the gate expression per batch
  policy.
