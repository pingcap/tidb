## Substitutions (documented in the test files' module docs)

1. `admin check table` on PARTITIONED tables (`adminCheckPartitionTable`,
   `modify_column_test.go:241`): this tier's `admin_check::check_table` is
   not partition-aware (measured: false `Inconsistent` on a partitioned
   clustered-handle PRIMARY, and row under-counts), so the admin-check
   assertion is dropped in the six running modify-column ports and Go's own
   exact result-set assertions carry the contract. `admin check` on
   UNPARTITIONED tables is unaffected.
2. `information_schema.columns` metadata reads
   (`checkPartitionColumnMeta`, `modify_column_test.go:711`) are answered
   from the same facts in `KvColumn` metadata (rendered default text,
   comment, NOT_NULL flag); the behavioral insert probes Go pairs with them
   all run unchanged.
3. `TestIssue57780`'s port adds one insert+select after Go's two DDL
   statements; Go asserts only that both succeed.
