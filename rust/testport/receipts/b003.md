Notes:

- `errors.New`/`errors.Errorf` are modeled by a local `MessageError`; Go's
  `errors.Trace` chain is modeled by a local `TraceError` whose
  `Error::source()` chain the crate's `terror_error_equal` walks, mirroring
  Go's `errors.Cause` traversal.
- `errors.Normalize(..., MySQLErrorCode(CodeExecResultIsEmpty))` in `TestJson`
  maps to `TerrorError::compatible(CODE_EXEC_RESULT_IS_EMPTY, ...)`.
- `FastGen("def: %s", "def")` uses the shared Go-format authority
  (`fast_generate` + `FormatArg`) so `%s` verb handling matches Go.
- go-parity-gap: `TestTraceAndLocation` asserts exact Go-runtime stack line
  arithmetic (`len(lines) - 2*sysStack == 9` after filtering GOROOT lines).
  Rust `std::backtrace::Backtrace` renders an implementation-defined format
  with no GOROOT concept; that numeric assertion has no faithful equivalent,
  so it is `#[ignore]`. The call-site-naming assertion (`containTerr`) is
  ported as a backtrace mention of this module/test.
- The crate already carries broad coverage in `tests/terror_source.rs`; this
  batch adds independent direct ports named after each Go test per the batch
  contract.
