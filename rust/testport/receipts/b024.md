`src/tests_mathutil.rs` tests in `crates/tidb-util` (crate convention:

## Change in this batch

Added the previously missing `RandomInput` subtest of TestStrLenOfUint64Fast:
1,000,000 deterministic PRNG-generated u64 inputs checked against decimal
string length (`str_len_of_uint64_fast_random_input`). Go uses
math/rand.Uint64(); Rust uses xorshift64* for determinism (the property under
test is input-independent).

No behavior gaps found; nothing needed `#[ignore]`.
