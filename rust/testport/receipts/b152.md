## Production mapping

Go `Extend(*mysql.SQLError)` maps to
`tidb_errmsg::extend(Option<&mut tidb_error::mysql::SqlError>)`. Both are
nil-safe, use the immutable extension set prepared when global config is
published, skip empty suffixes and invalid/unprepared regular expressions,
select the first (longest-pattern-first) match, trim trailing periods from
the message and suffix, and mutate the SQL error message in place. The MySQL
packet writer calls this ordinary error path before encoding the packet.

The Go package intentionally does not compile regular expressions itself;
that remains owned by the root `pkg/config` mapping. The prior Rust string
helper in `tidb-config` and its duplicate test carrier were removed.
