## Scope

The assigned `pkg/parser/ast.part3` slice contains eight Go unit-test
functions, ordered by file and line from `origin/master`:

- `pkg/parser/ast/sem_test.go`: `TestShowCommand`, `TestAdminCommand`,
  `TestBRIECommand`

  `TestFlushStatsDeltaScoped`, `TestRefreshStatsStmtDedup`

from `origin/master` with `git show`, not from the branch copy. The Rust tests
construct the corresponding typed AST states and verify SEM command mappings,
statistics restore/deduplication, and read-only classification.

`tidb-ast` uses `rust/scripts/aggregate-tests.rs`; standalone files under
`rust/crates/tidb-ast/tests/` are automatically included by `tests/all.rs`, so
no `lib.rs` or `main.rs` registration is required.
