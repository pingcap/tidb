## Measured Rust/Go divergences recorded (not approximated)

1. NULL→NOT NULL MODIFY over rows holding NULLs: Go answers
   `[ddl:1138]Invalid use of NULL value` (pkg/ddl/modify_column.go:840
   `return true, dbterror.ErrInvalidUseOfNull`); this tier answers MySQL
   1265 "Data truncated for column 'a' at row N"
   (`kv_table.rs::modify_column_in` → `DataTruncatedAtRow`). The
   refusal-and-intact-table contract is pinned running with the divergence
   cited in the test comment
   (`modify_column_null_to_not_null_rejects_rows_holding_nulls`).
2. `TestModifyColumnCharset`'s TableInfoVersion0 quirk: Go keeps column
   `b`'s utf8_bin charset when the table version is set to 0 before the
   MODIFY ("the behavior is not compatible with MySQL", Go's own comment);
   this tier has no table-version axis, so `b` follows the table default
   (utf8mb4_bin) like `a`. Pinned with the divergence cited in the test
   comment (`modify_column_charset_columns_follow_the_table_default_when_unset`).
3. `TestModifyColumnBetweenStringTypes`' closing non-strict arm
   (`set @@sql_mode=""` + `show warnings`) has no session sql_mode switch
   in this tier; the strict-path refusals (identical messages, code 1265)
   are pinned, and the arm is named in the test comment.

## Verification method

Every Go test was read from the snapshot commit and its intent re-derived
from the production source it exercises — e.g. the 1265 message shape comes
from Go's `types.ErrTruncated` rendering in `checkNullValue`
(pkg/ddl/modify_column.go:840-848), the `TestJobNeedGC` truth table from
pkg/ddl/job_worker.go:364, the `SubmitBatch` guards from
pkg/ddl/jobsubmit/submit.go:53, the invalid-TableMode error from
pkg/infoschema/error.go:114, and the masking-policy refusals from
pkg/errno/errname.go:1013 and :1159. Behavioral probes were run against the
live engine BEFORE pinning (enum re-order numeric filtering, CHAR
trailing-space fit, binary zero padding, boundary integer values, charset
resolution), so no assertion encodes an unverified "looks right" claim.
