## Source review

The authoritative package was read from `origin/master`, not from this
branch's Go snapshot:

```text
git show origin/master:pkg/util/sqlescape/utils.go
git show origin/master:pkg/util/sqlescape/utils_test.go
git grep -n '^func Test' origin/master -- 'pkg/util/sqlescape/*_test.go'
```

`utils_test.go` contains five `TestXxx` functions and four benchmarks. Each
test was checked against the implementation it exercises in master:

- `reserveBuffer` grows to `len(buf)*2+appendSize`, preserves the old prefix,
  and returns a slice whose length includes the requested append space.
- The byte and string backslash helpers share the same seven MySQL escape
  mappings and preserve all other bytes, including UTF-8 bytes.
- `escapeSQL`, `EscapeSQL`, and `FormatSQL` share one implementation. The
  existing Rust table has all 42 master rows, including nil versus empty byte
  slices, Go-width float rendering, zero/fractional times, raw JSON, named
  integer/string equivalents, identifier quoting, error prefixes, unknown and
  truncated specifiers, and discarded extra arguments.
- The `Must*` helpers panic with the underlying exact error text and otherwise
  return/write normally. The pre-existing inline Rust test checked the exact
  `MustEscapeSQL` panic but only checked that `MustFormatSQL` panicked; this
  batch adds the missing exact-message assertion and pins both success paths in
  `tests_sqlescape.rs`.
- `EscapeString` is the public wrapper around the same backslash helper and its
  three master vectors already match exactly.

The private-helper tests remain in the pre-existing inline
`sqlescape::tests` module, where they can access private implementation details.
The new public-wrapper parity assertion follows the crate's `tests_<area>.rs`
convention. No golden files or other fixtures are required. There are no
ignored parity gaps.
