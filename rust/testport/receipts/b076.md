## Structural facts that shaped the ports

- The byte-exact `HashCode` expectation in `TestScalarFunction`
  (`scalar_function_test.go:105`) decodes as: scalar-function flag `0x3`,
  compact-length-prefixed `"lt"` (`04 'l' 't'`), column flag plus
  sign-flipped big-endian `EncodeInt(UniqueID)` (`01 | 80 00*6 01`), and the
  constant flag plus mem-comparable float64 bits of +1.0
  (`00 | 05 | bf f0 00*6`; `math.Float64bits(1.0) ^ 1<<63`). The constant is
  a float because Go's compare-class construction casts both operands to the
  common real supertype inside `getFunction` → `newBaseBuiltinFuncWithTp` →
  `WrapWithCastAsReal`, folding the literal in place. The Rust tree is built
  with that post-inference shape directly (`builtin_compare.go`,
  `builtin.go:newBaseBuiltinFuncWithTp`).
- `NewOne()` is `Constant{Datum 1, TypeTiny unsigned}`
  (`pkg/expression/constant.go:37`); only its folded cast carries the value
  into `GetArgs()`.
- This workspace replaced Go's per-signature `builtinFunc` object model with
  name-keyed dispatch ([`crate::scalar_function`] BRIDGE DECISION). That
  single design decision removes three contract families Go's unit tests pin:
  concrete sig-type identity (`TestScalarFunction`'s Values half,
  `TestClone`), the bare-`baseBuiltinFunc` never-call guards over seven typed
  entrypoints (`builtin.go:353-378`, `TestBaseBuiltin`), and function-level
  `base.HashEquals` (`Hash64`/`Equals`, whose leaf-level halves ARE carried
  in `column.rs:132`/`constant.rs:162`). Each gap gets an anchored
  `#[ignore]` carrier instead of an approximation.
- `CanonicalHashCode` / `simpleCanonicalizedHashCode`
  (`scalar_function.go:618-682`) are deferred here (documented at
  `scalar_function.rs:29`), so `ExpressionsSemanticEqual`,
  `ScalarFunction.Hash64/Equals`, and the grouping-metadata hash-code-cleaning
  interplay of `TestColumnSubstituteGroupingCleansHashCode` cannot be driven
  without inventing behavior.
- `Filter` (`util.go`) has no standalone Rust carrier; its in-place twin
  `filter_out_in_place` IS carried (`expr_util/extract.rs:33`) and returns
  exactly the elements `Filter` would append. `TestFilter` is ported through
  that sibling symbol with the deviation documented in the module header;
  with one matching condition no ordering assumption is smuggled in.
- `TestHashGroupKey` (`util_test.go:358`) pins a codec-level invariant:
  `codec.HashGroupKey` row keys equal `codec.EncodeValue(datum)` row values.
  Both halves are transcreated inside `tidb-codec`
  (`hash_group_key_in_timezone`, `Encoder::encode_value_in_timezone`), which
  is a normal dependency of `tidb-expr`, so the property test lives in this
  batch's gate scope. Go's random generator
  (`bench_test.go:1237 fillColumnWithGener` → `newDefaultGener(0.2, eType)`)
  is replaced by a fixed matrix preserving the ~20% NULL density and boundary
  shapes; the asserted equality is generator-independent. Decimal keeps Go's
  `SetFlen(0)` special case (`util_test.go:373-376`); string resolves its
  collation through the same fallback Go hits
  (`collate.GetCollator("") → utf8mb4_bin`,
  `pkg/util/collate/collate.go:GetCollatorWithCollate`).

## Not verified locally

- The byte-exact `HashCode` pin covers the `lt(column#1 double, one)` tree
  only; Go's other literals (e.g. cast/hashcode variations elsewhere) are not
  re-pinned here.
- `TestHashGroupKey`'s substitution of Go's random generator with fixed
  matrices means boundary classes Go's seed happened to draw in a given run
  (NaN-adjacent floats, zero-time datetimes, >24h durations) are exercised
  only as far as the matrices here go; NaN/infinite floats were deliberately
  excluded since Go's masked-float encoding is only equality-comparable for
  finite values.
- Rows marked skipped-reason / ignored-gap above were not executed anywhere;
  their citations come from reading the named master sources.
- tidb-planner's `get_used_list` carrier (item 633) was inspected but not run
  inside this batch's gate (different crate scope; it is part of
  `cargo nextest -p tidb-planner`, not exercised here).
