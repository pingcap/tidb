## Go contract and Rust change

Go `ConvertColumnInfo` (`pkg/server/internal/column/convert.go`) sets the wire
`Charset` field with `mysql.CharsetNameToID(fld.Column.GetCharset())`. That is
the owning character set's default collation ID, not the selected column
collation: a `utf8mb4_general_ci` column still carries 46 (`utf8mb4_bin`) in
the column definition. Rust previously emitted `Collation::id()` directly,
which produced 45 for that column.

`tidb-exec::convert_result_field` now maps the typed collation to its owning
charset and emits the source default IDs (including the fixed compatibility
IDs for GBK and GB18030). The selected collation remains available for
execution and character-width calculation.
