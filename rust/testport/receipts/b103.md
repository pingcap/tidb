## Method notes

- Go tests were read from the master snapshot via `git show
  origin/master:pkg/ddl/...`; `master:<line>` citations above are master
  lines, re-checked this session (six corrections listed in the provenance
  note).
- A throwaway probe test was run against this tree BEFORE final assertions
  and deleted before commit. Probe results (session codes): enum origin
  default `Enum(value: 0)`; `non_exist_funcA()` 1105; `avg(a)` 1105; row
  value 1105; wrong-db/wrong-table qualifiers accepted (0); `KEY`+`PRIMARY
  KEY` 1068; MODIFY widen past max key length 0; DROP COLUMN auto_increment
  0; `concat` unique expression index 8200; over-long rename destination 0;
  RENAME missing-source-onto-existing 1146; `ALTER TABLE t RENAME TO t` 1050;
  `@x` 3102; `@@max_connections` 3102; `@y:=1` 0; `getvalue` 1105;
  `setvalue` 1105; `updatexml` 1105; ADD COLUMN rand default 1674;
  `double(0,0)` 0; GLOBAL TEMPORARY PRESERVE ROWS 8200; ALTER INDEX
  invisible 0; VALUES-both-DEFAULT insert 1364; clustered-PK expression
  index 0; default non-existent function 3770.
- `INSERT ... SET` is not in this tier's grammar; ports substitute the
  behaviorally identical column-list `INSERT` (same default-fill machinery).
- Local-temporary-table drop/truncate ports run through a
  `with_session_overlay` harness that attaches/detaches the session's local
  temporary tables around each statement, mirroring Go's
  `temptable.AttachLocalTemporaryTableInfoSchema` /
  `DetachLocalTemporaryTableInfoSchema` per-statement pairing.
- Go asserts several facts via `SHOW CREATE TABLE` text; the executor tier
  has no SHOW surface, so those ports pin the same fact on the stored
  metadata (column `DefaultValue`, index offsets/uniqueness, table charset)
  that the SHOW text renders. This substitution is noted per test in the
  module docs.
