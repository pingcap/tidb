## Measured implementation gaps

1. The synchronous `run_insert_on` path currently stores `NULL` for ordinary
   literal defaults when columns are omitted by `INSERT ... VALUES ()`. The
   six affected Go tests are retained as explicit ignored gaps rather than
   asserting incorrect rows. This is separate from the runnable
   `ALTER COLUMN SET DEFAULT` and explicit-value coverage.
2. The typed `Datum::Enum` and `Datum::Set` variants are rendered through their
   canonical member names in the runnable row helper, matching Go testkit's
   text view.
3. The Go DDL tests requiring temporary tables, sessions, information_schema,
   warning lists, failpoints, DDL jobs, schema states, transactions, allocator
   inspection, direct meta insertion, or mutable global configuration remain
   documentary gaps. No unsupported behavior is approximated to make tests
   pass.
