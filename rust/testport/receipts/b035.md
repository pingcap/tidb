Note on the new port: Go's `ZeroCopyDeserializeVectorFloat32` returns a zero
value alongside the error (`v.IsZeroValue()` asserted after `require.Error`);
the Rust `deserialize_vector_float32` returns a plain `Result` whose `Err`
branch carries no value, so that trailing assertion has no Rust counterpart.
The overflow-rejection behavior itself (the point of the Go test) is fully
pinned via checked arithmetic in `peek_vector_float32`.
