## Why every item is a documentary port

All sixty Go entries are execution benchmarks that require a live session:
`prepareBenchSession` (:72) boots a mock store + domain, per-scheme DDL +
`analyze table t` (`preparePointGet` :196, `insert1kRows` :203 doubling inserts,
`prepareIndexLookup` :218, `prepareTableScan` :224), then b.N loops of
`ExecutePreparedStmt` over a prepared statement with plan-cache hit counting
via `runPreparedPointSelect` (:852, hit-starved error at :892-894). The
`tidb-planner` crate has no executor/session/transaction layer (same boundary
already recorded for this same Go file's unprepared families in the b092
receipt; see `tests/tests_partition_plan_cache_benchmarks_source.rs`). No Rust
surface exists that could run these contracts, and none was approximated; each
port keeps Go's `Benchmark…` name shape so the gate's `not test(/bench/)`
filterset excludes it exactly as `go test` skips Benchmarks. Verify existence
separately with `-E 'test(tests_partition_prepared_plan_cache_benchmarks_source)'
--run-ignored only` → 60/60 pass (empty documentary bodies).
