## Coverage audit

Every part-4 Go test was cross-checked against the Rust crate. All 53 were
already exercised by existing Rust tests; each mapping below was verified by
reading the Go source on `origin/master` and the owning Rust module (not by
trusting comments). One row-level gap was found inside `TestToHashKey`: the Go
test's second half (`binTests`) had no Rust counterpart and is newly ported.
