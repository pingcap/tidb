# b100 — port `pkg/ddl` tests to `tidb-executor`

## Scope

The batch is the deterministic `func Test*`/`func Benchmark*` enumeration from
`pkg/ddl`, covering `affinity_test.go` through `column_test.go` in the branch's
Go snapshot. It contains 63 declarations: 61 tests and 2 benchmarks.

The owning Rust crate is `rust/crates/tidb-executor`. The crate's DDL layer is a
synchronous `Catalog`/SQL driver; it does not include TiDB's online-DDL job
queue, session testkit, failpoints, PD/GC services, Prometheus registry, or
cluster flashback machinery.
