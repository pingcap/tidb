by (file path, line number), chunked into groups of 60. Part1 = items 1-60
(affinity 1-5, attributes_sql 6-13, backfill_metrics 14-16,

those is nothing (7 baseline skips unchanged).

## Measured divergences (why three Go asserts are not pinnable here)

All measured in this session against the transcreated
`crate::ddl::alter_table` path:

1. `ALTER TABLE ... CHANGE a testx.t3.aa BIGINT` and `... CHANGE t.a aa
   BIGINT` are ACCEPTED (no error), where Go raises ErrWrongDBName 1102
   (column_modify_test.go:349-350) / ErrWrongTableName 1103
   (column_modify_test.go:351-352).
2. `k char(10) PRIMARY KEY -> TINYTEXT` is ACCEPTED, where Go raises 1170
   ErrBlobKeyWithoutLength (column_modify_test.go:367-369). The non-unique
   index case IS refused with 1170 and is pinned.
3. MODIFY/CHANGE of an indexed generated column is refused with the
   catch-all 1105 "ALTER TABLE MODIFY COLUMN of a generated column is not
   supported yet", where Go raises [ddl:3106]
   ErrUnsupportedOnGeneratedColumn (generated_column.go:419) — the subject
   of TestIssue37611.
