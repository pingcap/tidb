## Go-parity gaps

- `tests_simple_lru::get_peek_does_not_promote_entry` is marked
  `#[ignore = "go-parity-gap: SimpleLruCache has no non-promoting peek operation"]`.
  It pins the source precondition/order and documents the activation assertion;
  the Rust production API has no operation that can execute Go
  `(*SimpleLRUCache).Peek` without approximating it.

No supported behavior was approximated. For memory-guard cases, deterministic
probe values exercise the exact source comparisons: `0` is below a positive
quota with guard `0.0`, and `1` is above the zero threshold produced by guard
`1.0`. This avoids substituting host RAM or Rust allocator statistics for Go's
`memory.InstanceMemUsed` heap sample.
