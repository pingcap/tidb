## Faithfulness notes and required production alignment

Everything in-scope ran through the same five checks Go performs: template
fill → parse → extract-node restore under explicit flags → string equality →
re-parse + cleaned-tree equality. Where the Rust AST diverges structurally,
each row's Go node maps onto its owning Rust construct:

- `checkExpr` sentinels become a distinctive column expression the counting
  visitor filters on; per-row expected counts equal the number of reachable
  markers in the Go construction.
- Go nodes with no single Rust twin (`ShowStmt`, bare `FieldList` /
  `SetOprSelectList`) fold into the Rust statement owning the same children;
  zero expectations are preserved either way.
- Rust stores provenance INSIDE payloads that Go keeps on its cleaned node
  base state (`origin_position`, generated-expression text, comma-join
  parenthesization bits — Go's FROM tree has no such concept at all) and
  distinguishes `_utf8mb4` introducers / hex-written ENUM members that Go's
  post-clean structs collapse. The harness `clean_node_text` implements the
  Rust side of Go's `nodeTextCleaner` semantics: utf8mb4-introducer → plain
  string, UTF-8 ENUM-member `Bytes → Text` (`CleanElemIsBinaryLit`),
  function-name canonicalization + offset zeroing (`walkRewriteFuncName`
  happens parse-time in Go), and `Join.explicit_parens` clearing. Nothing
  else is normalized.

Three minimal production alignments were required to keep identity
extractions on the public Node.Restore surface, all confined to `tidb-ast`:

1. `stmt/ddl.rs`: `Create/Alter/DropPlacementPolicy` statement dispatch now
   consults the context flags they always carried (wrapping in
   `/*T![placement] ... */` or suppressing output) instead of dropping them —
   Go's own `Restore(ctx)` does exactly this; typed payload support already
   existed behind `PlacementRestoreMode`.
2. Small public subtree-restoration facets mirroring Go's public
   `Node.Restore()` per type (`IndexPart`, `ColumnPosition`,
   `ColumnDef`, `ColumnOption`, `TableConstraint`, `AlterTableAction`,
   `TableRef`, `JoinNode`, `Join`, `OrderItem`, `Limit`, `Assignment`,
   `WindowOver`, `WindowDef::restore_body`), delegating to existing internal
   renderers; `util::{back_quote, push_name_path}` became public re-exports.
3. Module-private helper widenings to `pub(crate)` where an existing
   same-crate pattern exists (`select.rs::restore_by_item_expr*`,
   window frame/bound entry points, `AlterTableAction` renderers,
   `push_column_position`). Bodies unchanged.
