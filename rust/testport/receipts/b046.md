## Scope definition

Following the deterministic rule documented in b042/b044: all 425 `func Test*`
under `pkg/statistics/**` on `origin/master`, sorted by (file path, line
number), chunked into groups of 60; part5 = items 201–260. The slice spans:

- `pkg/statistics/handle/handletest/analyze/analyze_test.go` (3 tests + TestMain)
- `pkg/statistics/handle/handletest/handle_test.go` (30 tests)
- `pkg/statistics/handle/handletest/initstats/init_stats_test.go` (8 tests + TestMain)
- `pkg/statistics/handle/handletest/lockstats/lock_partition_stats_test.go` (13 tests)
- `pkg/statistics/handle/handletest/lockstats/lock_table_stats_test.go` (4 tests)

Every test in this slice drives a full TiDB session through
`testkit.CreateMockStoreAndDomain` / `session.CreateStoreAndBootstrap`
(ANALYZE / LOCK STATS / SHOW STATS_LOCKED / stats-handle storage updates).
The tidb-stats crate owns only leaf primitives; session, domain, and the
statistics-handle runtime are external boundaries, so the ports are recorded
as go-parity-gap ignores (same pattern as b043/b044). The one pure leaf in the
slice's area — `GetConcurrency` from `handle/initstats/load_stats.go` — is
already pinned by `init_stats_concurrency_source.rs`, and the lockstats
diagnostics/filter leaves by `lock_messages_source.rs` /
`locked_tables_source.rs`. No behavior was approximated to make a test pass.

New file: `rust/crates/tidb-stats/tests/go_parity_b046_source.rs`.
