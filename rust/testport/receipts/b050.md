## Verification method

Every Go test below was re-read from the master snapshot
(`git show origin/master:pkg/ddl/placement/...`) and its intent re-derived from
the production code it exercises. The branch's Go snapshot is byte-identical to
origin/master for `pkg/ddl/placement` (`git diff origin/master HEAD --
pkg/ddl/placement/` is empty), so the existing Rust ports were checked
line-by-line against authoritative content: every table case, error kind
(`PlacementErrorKind` identity vs Go's `errors.Is`), golden JSON string,
order-insensitive `matchRules` comparison, and Go quirks were verified:

- `TestNewBundleFromOptions`: Go appends a copy of the previous case and
  mutates the shared `*PlacementSettings`, so "sugar syntax: normal case 2"
  also ends up with `Schedule: "even"`. The Rust port replicates this with an
  explicit mutation of the earlier case plus a comment.
- `TestString`: Go's failpoint `MockMarshalFailure` is a test-only thread-local
  in `bundle.rs`; both the golden JSON string and the empty-string failure
  path are asserted.
- `(*metaBundleSuite).checkPartitionBundle`: Go sets the expected bundle's
  `Index` to `RuleIndexPartition` but each rule's `Index` to
  `RuleIndexTable` (upstream quirk); the Rust port reproduces exactly that.
- `meta_bundle_test.go`'s mockstore/kv.RunInNewTxn/meta.Mutator stack is
  replaced by an in-memory `PolicyGetter` implementing only `GetPolicy`,
  which is the only meta call exercised; documented at the top of
  `tests/meta_bundle_test.rs`.

All 26 Go tests were already ported by prior integration work on this branch;
this batch's contribution is the per-test verification against origin/master.
No test-code changes were required: no divergence was found, so no
go-parity-gap `#[ignore]` markers were added.
