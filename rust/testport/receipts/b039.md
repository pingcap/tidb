## Scope

(24 top-level test functions; the file's benchmarks excluded). A coverage
audit showed this package's suite was already almost fully translated in
earlier batches across
`rust/crates/tidb-meta/tests/{transaction_source,key_prefix_and_element_source,iter_databases_source,job_name_go_vectors,go_vectors,structure_source}.rs`.
This batch re-derived each Go test's intent against `pkg/meta/meta.go` /
`meta_autoid.go` / `element.go`, verified the existing Rust assertions pin it,
and added the one test module for slices nothing pinned yet.
