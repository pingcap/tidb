## Gaps (consolidated)

- go-parity-gap: the online schema-change state machine (DDL job queue,
  per-state DML matrices, write/delete-reorganization backfills,
  `beforeRunOneJobStep`/`afterWaitSchemaSynced`/`afterRunOneJobStep`
  failpoint contracts, mid-statement schema invalidation 8028, outdated
  infoschema races) — `crate::ddl`'s module doc records the deferral; 18
  db_change tests are documentary ignores for this reason.
- go-parity-gap: ADD/DROP PRIMARY KEY, VECTOR/COLUMNAR indexes, ALTER
  SCHEMA, CREATE DATABASE SQL, TiFlash mocking — rejected or absent in this
  tier (measured this session).
- go-parity-gap: `IF [NOT] EXISTS` guard SKIP semantics: Go skips
  duplicates with a note (and the duplicate CREATE TABLE records an
  ErrTableExists NOTE warning); this tier reports 1060/1061 and records no
  warning (measured this session).
- go-parity-gap: errno/message divergences measured this session and
  omitted from running tests rather than approximated: 1061 duplicate-index
  message wording; 1050 rename-tables message qualification; 1091
  drop-column message wording; 8200 references/charset MODIFY forms → 1105
  here; 8200/1090 repeated/remove-all DROP COLUMN forms → 1091 here; 3107
  generated-column non-prior → 1054 here; SET `-1` insert accepted here vs
  1265; information_schema row content empty here.
- Go-only surfaces with no carrier: `admin check table/index`,
  `SHOW CREATE TABLE`/`SHOW INDEX` rendering (replaced where sound by
  persisted-metadata assertions over the same facts),
  `schematracker.Checker` enable/disable choreography, and Go's
  `mockstore.WithDDLChecker` harness.
