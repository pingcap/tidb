## Captured divergences (observed, never asserted as Go's behavior)

1. `insert into sett values(-1)` — Go errors 1265 (WarnDataTruncated);
   this tier accepts it and stores 0
   (`db_integration_test.go:177::TestIssue19229`).
2. `ADD COLUMN ... IF NOT EXISTS` — Go files a Note and skips duplicates
   (and reports 8200 for the mixed `dd`/`if not exists dd` form); this
   tier's ADD COLUMN action ignores the per-spec flag and errors 1060
   (`db_change_test.go:1556::TestDDLIfNotExists`,
   `db_integration_test.go:284::TestIssue5092`).
3. Generated-column prior-order check — Go checks existence against the
   whole table (1054) BEFORE prior-ness (3107); this tier's ADD COLUMN
   resolves against the preceding prefix only, so `as (c+1) FIRST` reports
   1054 where Go reports 3107
   (`db_integration_test.go:442::TestDependedGeneratedColumnPrior2GeneratedColumn`).
4. Serialized generated-dependency MODIFY answers Go-native 3108 where the
   Go PARALLEL job conflict reports 8200
   (`db_change_test.go:1124::TestParallelAddGeneratedColumnAndAlterModifyColumn`).
