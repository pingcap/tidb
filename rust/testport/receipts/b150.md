## Port status

Nine entries are runnable against executor-native behavior carriers:

- partial-index condition column extraction and index-column deduplication;
- basic row/index DML lifecycle;
- type insertion and retrieval;
- multiple NULL entries in a unique index;
- row-key encoding/decoding and invalid-key rejection;
- unsigned primary-key retrieval;
- row iteration/counting; and
- unique-index constraint rejection during update.

The remaining 51 entries are explicit `#[ignore]` carriers. They are not
silent omissions:

- column, error-code, option, assertion, default, cast, and index codec tests
  are marked `go-parity-carrier` where complete behavior already lives in the
  owning Rust crate/module;
- cache-table scan/read/write, lease, metric, and failpoint tests require the
  Go cache wrapper, lease coordinator, session variables, and timing/failpoint
  machinery;
- common-handle/index-value tests are carried by `tidb-tablecodec` rather than
  duplicated in the executor source inventory;
- partial-index and DDL write-only/temporary-index tests require the Go DDL
  state machine and transaction coordination; this executor deliberately
  refuses unsupported partial indexes;
- mutation-checker and `StateRemote` tests require Go transaction-buffer or
  remote-storage interfaces;
- hidden-column, view-column, table metadata, optimistic transaction,
  assertion-level, untouched-index write-accounting, and duplicate-key-mode
  tests require session/infoschema, failpoint, or transaction APIs not exposed
  by this executor-only boundary; and
- Go `TestMain` and benchmark harnesses are not Rust behavior tests.
