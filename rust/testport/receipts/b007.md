## Scope note

The batch manifest maps `pkg/meta/model` to crate `tidb-metadef`, but the
production Rust port of `pkg/meta/model` lives in `tidb-model` (which already
pins most Go tests verbatim in in-crate `#[cfg(test)]` modules). To keep the
gate scoped to the assigned crate, `tidb-model` (+ `tidb-ast`,
`tidb-datatype`, `tidb-config`, `serde_json`) was added as a **dev-dependency**
of `tidb-metadef` and the new pins were written as integration tests in
`crates/tidb-metadef/tests/model_parity_source.rs`. Go tests already pinned by
existing `tidb-model` tests were verified against the Go source and are listed
below as "already ported, verified".
