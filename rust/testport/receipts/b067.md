## Structural facts that shaped the ports

- There is NO separate vectorized signature tier in this workspace:
  `Expression::eval` walks chunks row-by-row through a single code path.
  Every Go `_vec_`/`_generated_` differential harness therefore has nothing
  to differentiate against, and is recorded as an `#[ignore]` stub whose
  body-text lists which scalar value content already pins the family
  (matching the b066 precedent for `TestCastIntAsIntVec`).
- Go fixtures derive temporals from `time.Now()` at package init
  (`builtin_cast_test.go:256-276`). All temporal expectations here pin the
  statement clock at 2020-10-10 (UTC) via the module-local `Ctx`, so
  "curTimeString" = `2020-10-10 12:59:59`.
- GBK rows: Go rewrites string CONSTANTS through
  `charset.Transform(OpEncode)` under `character_set_connection=gbk`. Direct
  dispatch ports feed PRE-ENCODED byte datums (both origin AND password where
  Go would transform both), following `builtin_ext/crypto.rs`'s existing
  fixture convention. The connection-aware rewrite regression additionally
  drives valid GBK and unrepresentable-character rows through the ordinary
  `to_binary` boundary.
- COMPRESS golden streams: Go pins its zlib encoder's exact DEFLATE bytes;
  the Rust transcreation deliberately frees the stream layout while keeping
  the `<len LE u32><zlib>` framing and both inverse functions (documented in
  `builtin_ext/crypto.rs`'s module header). Framing, round-trips and every
  deterministic UNCOMPRESS/UNCOMPRESSED_LENGTH row are pinned instead;
  Go's hand-crafted payload bytes ARE asserted verbatim because they decode
  independent of any encoder.
- `refineArgs`' `isExceptional` whole-comparison folds and the NE-vs-DOUBLE
  argument re-type are deliberate shape-only drops in `builtin_compare.rs`
  ("costs speed, never an answer"); the affected 12 rows of
  `TestCompareFunctionWithRefine` pin the SURVIVING shapes plus a gap stub,
  and mirror-side expected constants come verbatim from the Go table.

## Not verified locally

- No Go toolchain in this worktree: expected values come from reading the
  master snapshot sources (tables copied verbatim), not from executing them.
- Go testing.B microbenchmark equivalents were never intended to run here;
  they are listed as skipped-reason rows only.
- The memory-tracker contract (`StmtCtx.MemTracker`, LogOnExceed hook,
  BytesConsumed/MaxConsumed accounting) behind three Uncompress tests lives
  outside tidb-expr and was read (for location evidence) but neither built
  nor executed here.
- tipb ScalarFuncSig code identity sub-assertions (`f.PbCode() ==
  f.Clone().PbCode()`) present in several info/compare-family Go tests
  remain unverifiable until tipb signature codes exist in this workspace's
  expression model.
