## Risks

- **Correctness:** the six runnable tests cover the complete behavior exposed
  by the Rust apply-cache and vector-group-checker carriers. The 19 ignored
  tests do not claim parity for session SQL, PD/resource control, asynchronous
  statistics, runaway-query state, or local MPP coordination.
- **Compatibility:** only test code and one `#[cfg(test)]` module registration
  changed; no production API, dependency, or runtime path changed.
- **Performance:** no production hot path changed. The concurrent apply-cache
  test uses the same two-key alternation and iteration count as the Go test.
