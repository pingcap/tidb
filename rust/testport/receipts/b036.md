## Coverage audit

Before porting, every `func Test*` in `pkg/types` on `origin/master` was
cross-checked against the existing Rust tests in `rust/crates/tidb-datatype`
(inline `mod tests` blocks, `src/*_tests.rs`, and `tests/*_source.rs`). The
crate already carries near-complete translations of this package's suite;
only the gaps below remained. Go test functions whose behavior is exercised
by an existing differently-named Rust test are listed as `ported (existing)`.
