## Method evidence (re-derived during THIS session)

- Wrong-parameter-count refusals are Go's builder gate, not a runtime check:
  `funcs[name].getFunction` validates via `VerifyArgsWrapper`
  (`pkg/expression/builtin.go:606`). Pinned through its transcreation,
  `tidb_expr::builtin_registry::verify_args_by_count`.
- Constant `-x` overflow promotion comes from
  `unaryMinusFunctionClass.typeInfer`'s `handleIntOverflow`
  (`pkg/expression/builtin_op.go:1106-1124`): constants promote to Decimal
  keeping magnitude; column operands keep Int and error.
- `COT(0)` raises `[types:1690]DOUBLE ... 'cot(...)'` at
  `pkg/expression/builtin_math.go:1774`; the Rust tier reports the same
  DOUBLE-overflow event (`EvalError::FloatOverflow`).
- Go's `getWarning` trig rows assert success + exactly one truncation
  warning and never read the value; the warning count is what the new Rust
  test pins, one per coercing call.
- `BIN_TO_UUID(bin, 1)` swap spelling is quoted straight from the
  `TestBinToUUID` table: `baba1026-780c-6ccd-9564-5b8c656024db`.

## Gaps recorded during this batch

1. `crc32_gbk_charset_connection_rows` — `#[ignore]`,
   `// go-parity-gap`: Go sets `character_set_connection=gbk` so CRC32's
   string constants arrive re-encoded as GBK bytes (一=D2BB,
   一二三=D2BB B6FE C8FD, expected 2925846374 / 3461331449). No Rust value
   domain can represent a session-re-encoded string constant yet.
2. `sleep_vectorized_timing_strict_real_duration_and_kill_signal` —
   `#[ignore]`, `// go-parity-gap`: wall-clock bounds (SLEEP(0.5) >= 0.5s)
   and `SQLKiller.SendKillSignal(QueryInterrupted)` interruption have no
   counterpart on the Rust evaluation-context contract; the errctx warn/
   strict VALUE halves are ported in the sibling test above.
3. Logic/bit family rows whose first operand is `errors.New("must error")`
   require an operand that FAILS DURING EVALUATION; the Rust expression model
   has no such leaf a unit test can build. All non-error rows of those tables
   are ported; recorded as skipped rather than approximated.
4. `COT(0)`'s Go message embeds the formatted argument ('cot(0)') via
   GenWithStackByArgs; the Rust error carries the overflow event without that
   argument text. Display-shape residual noted in
   `cot_zero_overflows_as_double_error`'s doc comment.
5. TestNameConst's temporal/duration/json ARGUMENT arms are pinned only as far
   as the pre-existing `name_const_preserves_representable_value_domains`
   comment documents (seed Datum domain boundaries); unchanged here.
