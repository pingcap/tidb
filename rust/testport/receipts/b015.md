# b015 — port `pkg/util/chunk` unit tests from Go (part 1)

Batch: b015
Go package: `pkg/util/chunk` (`origin/master` snapshot)
Owning crate: the chunk code lives in **`tidb-chunk`**, not `tidb-util`
(`pkg/util/chunk` was transcreated as `rust/crates/tidb-chunk`; `tidb-util`
only hosts shared utilities such as `disk::SpillStorage`). All tests were
therefore added to `rust/crates/tidb-chunk/src/tests_*.rs`, and the gate was
run for both crates.
