## Closed gaps

- Successful collation substitution now returns the input spelling, rather
  than leaking registry canonicalization.
- `ImmutableKey` now returns borrowed input for raw and padded binary
  collators and owned keys for transforming collators.
- Wildcard compilation accepts arbitrary bytes and applies Go's byte/rune
  decoding family exactly.
- The pinyin stub panics with Go's `implement me` contract.
- UCA 9.0 surrogate markers use the zero value of Go's missing map lookup.
- The immutable-key benchmark calls `immutable_key`, not `key`.
