# testport batch b045 — pkg/statistics (part4) → tidb-stats

Gate: `cargo nextest run --locked -p tidb-stats --no-fail-fast` (run from `rust/`).

## Scope

All top-level `func Test*` in `pkg/statistics` on `origin/master`
(`builder_test.go`, `cmsketch_test.go`, `estimate_test.go`, `fmsketch_test.go`,
`histogram_test.go`, `merge_global_test.go`, `sample_test.go`, `scalar_test.go`,
`statistics_test.go`, `table_test.go`, `integration_test.go`; benchmarks and the
`handle/`, `util/`, `asyncload/` subpackages excluded). Each Go test was
re-derived against its source; tests already pinned by earlier batches were
verified, not re-translated. New ports live in
`rust/crates/tidb-stats/tests/pkg_statistics_go_tests_source.rs`.

During porting of TestSampleSerial, the Rust fixture initially modeled the
recordSet value shifts as divisibility-based; running the Go test on a master
worktree proved the shifts are index-stepping (`for i := start; i += 3`), which
changes the FM-sketch golden NDV from 6200 to the real 6232. The Rust fixture
now reproduces the exact stepping and pins the Go golden.
