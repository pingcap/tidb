## Current-master follow-up: EXTRACT composite fractional values

The complete current-master `pkg/expression` tree was re-inventoried before
this follow-up from Go `origin/master` (`17daba3dfd`): 208 tracked artifacts,
146,247 lines, 195 Go files, 80 test/support files, 11 BUILD files, and 21
generated/generator artifacts. No platform-specific files or binary fixtures
were present. The Go authority was reread in `pkg/types/time.go`:
`ExtractDatetimeNum` and `ExtractDurationNum` append the parsed microsecond
component to each `*_MICROSECOND` composite formula.

The Rust composite extractor previously called `parse_time_hms`, which rejects
the `.123456` suffix, and discarded the suffix from bare durations. It now
retains up to six validated fractional digits and applies the source formulas
for `SECOND_MICROSECOND`, `MINUTE_MICROSECOND`, `HOUR_MICROSECOND`, and
`DAY_MICROSECOND` in both the datetime and duration paths. The regression
`extract_composite_units_over_fractional_strings_match_source` covers all ten
master composite rows plus a fractional TIME input.
